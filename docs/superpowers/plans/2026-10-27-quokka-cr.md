# /quokka:cr Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `/quokka:cr`, a command and skill that run the change-request flow (list, detail, design, hand-off, build, close, cleanup), plus the QG and INS project files and a global install target.

**Architecture:**
- `commands/quokka/cr.md` is a thin entry point. It invokes `skills/quokka-cr/SKILL.md`, a router to one reference file per sub-command or mechanism.
- Project settings ship as `projects/*.json`. Each dev's machine settings live in `~/.quokka/cr/<slug>.local.json`.
- `bin/install.js` installs the CR command and skill globally (`~/.claude`), and the shipped project files to `~/.quokka/cr/projects/`. Everything else stays per-project, as today.

**Tech Stack:** Markdown skills, JSON config, Node ≥16 installer, a plain-assert test (`node test/install.test.js`).

**Spec:** `docs/superpowers/specs/2026-10-27-quokka-cr-design.md`

## Global Constraints

- CR ids: `QG-CR-NN`, `INS-CR-NNN`.
- Artifact names: `<PFX>-CR-List`, `<PFX>-CR-<n>-Detail <title>`, `<PFX>-CR-<n>-Design <title>`, `<PFX>-<Surface>-Design-Main`, `<PFX>-<Surface>-DS`.
- Identity comes from the `gh` / Bitbucket / `acli` login, never from the shared Claude account.
- The skill never merges, never pushes without the dev's yes, and never deletes outside `cleanup`'s typed per-CR confirmation.
- Every sub-command ends with a next-command line.
- Codex review: `node <codex plugin>/scripts/codex-companion.mjs review --wait --base <ref> --scope branch --cwd <repo>`.

## Review Focus

- Re-running the installer when the global files already exist must report "Already up to date" and must not touch `~/.quokka/cr/projects/local/`. Test: `localSurvivesReinstall`.
- Uninstall removes the global CR command, skill and shipped project files, but keeps `local/` and `*.local.json`. Test: `uninstallKeepsLocal`.
- The per-project install no longer copies `cr.md` or `quokka-cr`, so no duplicate command appears. Test: `crNotInProjectInstall`.
- The project JSON files parse, and every artifact id is 22 characters. Test: `projectFilesValid`.
- The installer must never write to the real HOME during tests: the global root comes from `QUOKKA_HOME` (default `os.homedir()`).
